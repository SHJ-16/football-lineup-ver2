# 축구 라인업 생성기

쿼터별 선발 라인업과 교체 명단을 짜고, 1~4쿼터 라인업을 이미지 한 장으로 복사할 수 있는 웹 앱입니다.

**바로 사용하기:** https://shj-16.github.io/football-lineup-ver2/

## 주요 기능

- **쿼터별 라인업:** 1~4쿼터의 포메이션, 선발, 교체 명단을 따로 구성합니다.
- **포메이션 선택:** 4-3-3, 4-4-2, 3-4-3, 4-2-3-1 중에서 고를 수 있습니다.
- **선수 배치:** 경기장에서 선수를 드래그하거나 터치해 옮깁니다.
- **위치 교환:** 선수 두 명의 위치와 포지션을 맞바꿉니다.
- **선수 관리:** 선수를 추가하고 이름을 수정하며, 선수별 출전 쿼터를 확인합니다.
- **쿼터 계산기:** 총 인원과 필드 플레이어 인원으로 선수별 출전 쿼터 수를 계산합니다.
- **이미지 복사:** 1~4쿼터 라인업을 PNG 이미지 한 장으로 클립보드에 복사합니다.
- **저장:** 저장하기를 누르면 현재 브라우저에 라인업을 저장합니다.

## 쿼터 계산 방식

총 인원에서 골키퍼 1명을 뺀 인원에게 필드 출전 자리를 나눕니다.

예를 들어 총 13명, 필드 플레이어 10명이면 다음과 같습니다.

- 전체 출전 자리: 10명 × 4쿼터 = 40자리
- 골키퍼를 뺀 인원: 13명 - 1명 = 12명
- 결과: 8명은 3쿼터, 4명은 4쿼터 출전

## 실행 방법

설치할 것은 없습니다. 위 링크로 접속해서 사용하면 됩니다.

코드를 수정하면서 로컬에서 실행하려면 다음 명령어를 사용합니다.

```bash
git clone https://github.com/SHJ-16/football-lineup-ver2.git
cd football-lineup-ver2
python3 -m http.server 8000
```

그다음 브라우저에서 http://localhost:8000 으로 접속합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조 |
| `app.js` | 라인업, 계산기, 저장, 이미지 복사 기능 |
| `lineup-v2.css` | 화면 스타일 |

`style.css`, `mobile.css`, `name-inputs.css`, `name-inputs.js`는 현재 `index.html`에서 불러오지 않습니다.

## 기술 스택

HTML, CSS, JavaScript

## 참고

라인업은 브라우저의 `localStorage`에 저장됩니다. 다른 기기나 브라우저에서는 저장한 내용을 볼 수 없고, 브라우저 데이터를 지우면 함께 삭제됩니다.
